# IT Documentation

Русскоязычная база официальной технической документации в формате Markdown для GitHub и Obsidian.

## Цель

Брать официальную документацию технологий, переводить её на русский язык и сохранять структуру, технический смысл, примеры, код и навигацию максимально близко к первоисточнику.

## Принципы

- источник истины — официальный сайт и официальный репозиторий проекта;
- перевод привязан к конкретному release/tag или зафиксированному commit upstream;
- один upstream-документ соответствует одному Markdown-файлу перевода, когда это возможно;
- имена файлов сохраняются максимально близко к upstream для удобного сравнения и синхронизации;
- код, SQL, API, имена классов, методов, параметров и конфигурационных ключей не переводятся;
- для Obsidian используются YAML frontmatter, WikiLinks, MOC и backlinks;
- для производных материалов сохраняются лицензия и атрибуция исходного проекта.

## Статусы перевода

- `todo` — перевод не начат;
- `in_progress` — перевод выполняется, неполон либо требует восстановления полного соответствия upstream;
- `translated` — полный перевод выполнен;
- `reviewed` — полный перевод дополнительно сверен с зафиксированным upstream;
- `outdated` — upstream изменился после перевода.

> [!important]
> Краткий пересказ, конспект или сокращённая адаптация не считаются статусом `translated`. Для полного перевода должны сохраняться все существенные разделы, пояснения, примеры, warnings/notes и code blocks исходного документа.

> [!note]
> Это неофициальная русскоязычная база переводов. Она не является официальной документацией Apache Software Foundation, The Go Authors или других upstream-проектов.
