# Скачивание и установка Go

Здесь описан быстрый способ скачать и установить Go.

Если нужна дополнительная информация по установке:

- [[manage-install|Управление установками Go]] — установка нескольких версий и удаление Go;
- [Installing Go from source](https://go.dev/doc/install/source) — получение исходников, самостоятельная сборка и запуск Go.

Официальные установочные файлы доступны на странице [go.dev/dl](https://go.dev/dl/).

## Установка Go

Выберите инструкции для своей операционной системы.

### Linux

1. Удалите предыдущую установку Go, удалив каталог `/usr/local/go`, если он существует. Затем распакуйте скачанный архив в `/usr/local`, чтобы получить новое дерево Go в `/usr/local/go`:

```bash
rm -rf /usr/local/go && tar -C /usr/local -xzf go1.27.1.linux-amd64.tar.gz
```

Для выполнения команд могут потребоваться права `root` или `sudo`.

> [!warning]
> Не распаковывайте новый архив поверх существующего `/usr/local/go`. Такой способ известен тем, что может приводить к повреждённой установке Go.

2. Добавьте `/usr/local/go/bin` в переменную окружения `PATH`. Например, добавьте строку в `$HOME/.profile` или `/etc/profile` для системной установки:

```bash
export PATH=$PATH:/usr/local/go/bin
```

Изменения profile-файла обычно начинают действовать после следующего входа в систему. Чтобы применить их сразу, выполните команду напрямую либо загрузите profile:

```bash
source $HOME/.profile
```

3. Добавьте `$HOME/go/bin` — стандартный каталог бинарных файлов Go — в `PATH`, чтобы запускать инструменты, установленные через `go install`:

```bash
export PATH="$PATH:$(go env GOPATH)/bin"
```

Эту строку можно добавить в `$HOME/.profile` или `$HOME/.bashrc`.

4. Перезапустите открытые terminal sessions, чтобы изменения вступили в силу.

5. Проверьте установку:

```bash
go version
```

6. Убедитесь, что команда вывела установленную версию Go.

### macOS

1. Откройте скачанный package-файл и следуйте инструкциям установщика.

Пакет устанавливает Go в `/usr/local/go` и добавляет `/usr/local/go/bin` в `PATH`, создавая файл `/etc/paths.d/go`.

2. Добавьте `$HOME/go/bin` в `PATH`, чтобы использовать инструменты, установленные через `go install`. Добавьте следующую строку в `~/.zshrc` или `~/.bash_profile`:

```bash
export PATH="$PATH:$(go env GOPATH)/bin"
```

3. Перезапустите terminal sessions.

4. В новой сессии терминала проверьте установку:

```bash
go version
```

5. Убедитесь, что команда вывела установленную версию Go.

### Windows

1. Откройте скачанный MSI-файл и следуйте инструкциям установщика.

По умолчанию Go устанавливается в `Program Files` или `Program Files (x86)`. Путь можно изменить. После установки закройте и заново откройте уже запущенные command prompts, чтобы обновлённые переменные окружения стали видимы.

2. Проверьте установку:
   1. Откройте меню **Start**.
   2. Введите `cmd` и нажмите **Enter**.
   3. Выполните:

```text
go version
```

   4. Убедитесь, что команда вывела установленную версию Go.
