# Editor plugins и IDE

## Введение {#introduction}

В этом документе перечислены часто используемые editor plugins и IDE из Go ecosystem, которые делают разработку на Go продуктивнее и удобнее.

Более полный список editor support и IDE для разработки на Go доступен в [Wiki: IDEs and Text Editor Plugins](https://go.dev/wiki/IDEsAndTextEditorPlugins).

## Варианты {#options}

Go ecosystem предоставляет различные editor plugins и IDE, улучшающие повседневную работу с editing, navigation, testing и debugging.

- [Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=golang.go) — расширение Go предоставляет поддержку языка Go.
- [GoLand](https://www.jetbrains.com/go) — распространяется как самостоятельная IDE или как plugin для IntelliJ IDEA Ultimate.
- [vim](https://github.com/fatih/vim-go) — plugin vim-go предоставляет поддержку языка Go.

Это только несколько наиболее популярных решений. Более полный community-maintained список [IDE и text editor plugins](https://go.dev/wiki/IDEsAndTextEditorPlugins) доступен в Wiki.
