# Проверка Apache Iceberg: 26 октября 2026

## Результат

Раздел содержит все **42 страницы** навигации официальной документации Iceberg **1.12.0**. Добавлены самостоятельное обучение, воспроизводимая лабораторная и справочник по задачам. Лабораторная успешно выполнена на Spark 3.5.5 / Scala 2.12 / Java 17 / Iceberg 1.12.0.

Статус всего перевода остаётся **in_progress**. Наличие страниц и совпадение кода не подтверждают сохранение каждого пояснения, предупреждения или строки таблицы. Смысловая сверка всех 42 страниц в полном объёме не завершена. Учебный материал можно проходить сейчас; при использовании параметров интеграций сверяйтесь с закреплённым оригиналом.

## Уточнение первоначальной оценки

В первоначальной оценке упоминалось 58 блоков кода в `spark-procedures.md` против 40 в переводе. **Это не означает отсутствие 18 примеров.** Несколько SQL-вызовов в переводе объединены в один fenced block. При дополнительном сопоставлении SQL-примеры этой страницы обнаруживаются в переводе с изменённым регистром, форматированием и объединением блоков. Схема истории snapshots также присутствует.

Подтверждённые пропуски установлены сравнением конкретного содержания: например, отсутствовавшие примечания о кэше Spark и разделы Dell ECS. Для остальных страниц числовые различия используются как список мест для проверки, а не как доказательство неполноты.

## Порядок оставшейся смысловой сверки

1. `aws.md`: исходные команды часто заменены короткими конфигурационными фрагментами; проверить весь контекст и зависимости.
2. `flink-configuration.md`, `flink-queries.md`: восстановить полное соответствие пояснений и примеров, проверить ограничения streaming и options.
3. `spark-procedures.md`: пройти аргументы, defaults, outputs и оговорки каждой процедуры, не ориентируясь на число заголовков.
4. Остальные страницы: проверить абзацы, ссылки, предупреждения и таблицы; только после такой сверки присваивать `reviewed`.

Первые четыре страницы/группы имеют статус `in_progress` в соответствующих файлах. Остальные существующие `translated` остаются историческими статусами перевода; они не означают выполненное review.

Учебные главы маркируются как `material_type: learning`, лабораторная как `lab`, справочник как `reference`. Их не следует учитывать как дополнительные переведённые upstream-страницы.

## Повторить проверки

Из корня репозитория:

```sh
python3 01-apache-iceberg/_meta/source-parity.py \
  --source-root /tmp/iceberg-source-1.12.0 --download --write
python3 01-apache-iceberg/_meta/validate.py
bash -n 01-apache-iceberg/labs/run.sh
bash 01-apache-iceberg/labs/run.sh
```

В CI ссылки и метаданные проверяются автоматически при изменениях раздела. SQL-лабораторная включается ручным `workflow_dispatch`; локальный успешный запуск не является свидетельством запуска GitHub Actions.
