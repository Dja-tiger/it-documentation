# Apache Iceberg

Русскоязычный перевод официальной документации Apache Iceberg.

## Базовая версия

- Apache Iceberg: **1.12.0**
- upstream tag: `apache-iceberg-1.12.0`
- исходная навигация: `docs/mkdocs.yml`
- официальная документация: https://iceberg.apache.org/docs/latest/
- исходный каталог: https://github.com/apache/iceberg/tree/apache-iceberg-1.12.0/docs/docs

## Организация

Файлы в `docs/` сохраняют имена upstream-файлов. Иерархия официальной документации воспроизводится в [[MOC]]. Это позволяет сравнивать перевод с upstream, отслеживать изменения, использовать backlinks/graph Obsidian и не дублировать один upstream-файл из-за нескольких пунктов навигации.
