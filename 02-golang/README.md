# Go / Golang — русская документация

Этот каталог содержит неофициальный русскоязычный перевод официальной документации языка Go.

## Baseline

- стабильная линия: **Go 1.27**;
- patch baseline: **Go 1.27.1**;
- исходники toolchain/spec/runtime: `golang/go`, tag `go1.27.1`;
- исходники go.dev User Manual и tutorials: `golang/website`, commit `575a6925e2d55ad160ed77f402bfaa4ec7458749` от 2026-10-11;
- дата фиксации перевода: 2026-10-12.

## Что входит в перевод

В разделе переводятся текстовые страницы официальной документации Go: установка, начало работы, организация кода, модули, toolchain, спецификация языка, модель памяти, assembler guide, GODEBUG, Effective Go, FAQ, диагностика, GC/PGO, tutorials, database/sql, security, fuzzing и release notes актуальной стабильной линии.

Документация стандартной библиотеки на `pkg.go.dev/std` генерируется из комментариев исходного кода тысяч API-символов. Она учитывается в manifest отдельно как generated API и не смешивается с ручным переводом руководств.
