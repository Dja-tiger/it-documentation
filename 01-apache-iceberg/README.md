## Готовность

Все **42 страницы** из навигации версии 1.12.0 присутствуют. Учебная лабораторная проверяется отдельно от исходных примеров. Полнота перевода всех пояснений и предупреждений ещё не подтверждена постраничной сверкой; в крупных страницах есть сокращения. Статус раздела — **in_progress**.

Автоматическая [сверка структуры](_meta/source-parity.md) фиксирует наличие страниц, заголовки, блоки кода и ключи таблиц. Разница числа блоков сама по себе не доказывает пропуск: часть примеров объединена. Ограничения проверки и конкретные исправления указаны в отчёте.

## Организация

Файлы в `docs/` сохраняют имена upstream-файлов. Иерархия официальной документации воспроизводится в [[MOC]]. Это позволяет сравнивать перевод с upstream, отслеживать изменения, использовать backlinks/graph Obsidian и не дублировать один upstream-файл из-за нескольких пунктов навигации.

`learn/`, `labs/` и `reference/` содержат дополнительные материалы; для них не используется статус `translated`. В `docs/` могут сохраняться шаблоны upstream (`{{ icebergVersion }}` и другие). Для первого запуска используйте лабораторную с конкретными версиями и проверенными командами.

## Проверки

Из корня репозитория:

```sh
python3 01-apache-iceberg/_meta/validate.py
bash 01-apache-iceberg/labs/run.sh
```

Первая команда проверяет локальные ссылки, изображения, anchors, frontmatter, закрытие code fences и актуальность отчёта по хешам переводов. Вторая запускает SQL-практику в одноразовом контейнере. Проверка структуры не заменяет смысловую сверку перевода.
